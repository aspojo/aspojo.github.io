cpp_app Docker部署说明

1. 导入镜像到本地仓库

镜像文件名：

cpp_app.tar

执行导入命令：

docker load -i cpp_app.tar

查看导入后的镜像：

docker images

2. 修改镜像名称

将镜像重命名为：

cpp_app:3.3.28

执行命令：

docker tag 741384f55e7d cpp_app:3.3.28

验证：

docker images

3. 使用 docker-compose 启动容器

创建 docker-compose.yml：

version: '3.8'

services:
  cbi_agent:
    image: cpp_app:3.3.28
    container_name: cbi_agent

    command:
      - cbi_agent

    volumes:
      - /var/local/bimss/conf/wxz:/opt/mss/conf
      - /var/local/bimss/logs/wxz:/opt/mss/log

    stdin_open: true
    tty: true

启动容器：

docker compose up -d --force-recreate

查看容器状态：

docker ps

查看容器日志：

docker logs -f cbi_agent

停止容器：

docker compose down
